# Aset

Hanya gambar yang benar-benar dimuat game yang disimpan di sini, dalam versi ringan (WebP/PNG kecil):

| Folder | Isi |
|---|---|
| `ui/` | Latar layar awal dan lobi, logo, tombol, koin, kotak oranye |
| `misi/` | Latar dan planet layar Pilih Misi |
| `rakit/` | Ikon komponen dan gambar layar Rakit |
| `frame/` | Bingkai layar terbang |
| `debrief/` | Bintang dan Pok-Pok di layar Debrief |
| `wahana/` | Gambar roket |
| `textures/` | Tekstur Bumi dan Bulan dari NASA |
| `music/` | Musik latar (`background.mp3`, berulang di semua layar) |

`netral.svg`, `cemas.svg`, `senang.svg` = ekspresi Pok-Pok; `back-button.svg` = tombol Kembali.

File desain asli dari tim DKV (ukuran besar) ada di `docs/desain/aset-asli/` dan tidak ikut dimuat game.
Aset baru: kecilkan dulu (squoosh.app), nama huruf kecil dengan tanda hubung, lalu taruh di folder yang sesuai.
